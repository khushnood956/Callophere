\# Callophere | Medicare BPO Campaign



A high-performance, single-page static website built for a Medicare-focused Business Process Outsourcing (BPO) campaign. This project is designed for immediate, zero-backend deployment with a strict adherence to a "Data-Driven Corporate" dark theme.



\## 📐 Design Philosophy \& Constraints



This project actively rejects modern SaaS design clichés in favor of a highly secure, clinical, and operationally mature aesthetic. 



\*\*Strictly Enforced Rules:\*\*

\*   \*\*Theme:\*\* Deep Charcoal / Dark Slate background (no pure black, no pure white).

\*   \*\*Geometry:\*\* 100% sharp edges (0px border radius on all elements). Thin 1px borders.

\*   \*\*Interactions:\*\* Instant state changes only. Zero hover animations, transitions, or soft fades.

\*   \*\*Visuals:\*\* No drop shadows, harsh gradients, radial orbs, sparkle icons, or emojis.

\*   \*\*Layout:\*\* Asymmetrical, editorial grids. No standard "3-feature cards in a row" sections.
